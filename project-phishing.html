Phishing Detection System

A machine learning system to detect phishing websites using URL and feature analysis.

Problem

Phishing attacks are a major cybersecurity threat where fake websites trick users into revealing sensitive information. Most users cannot easily identify malicious websites, leading to data theft and financial loss.

Solution

This system uses machine learning algorithms to analyze URL patterns and webpage features. Based on trained data, it classifies websites as phishing or legitimate and alerts users before interaction.

Tech Stack

  • Python
  • Machine Learning (Scikit-learn)
  • Flask
  • HTML / CSS

Key Features

  • URL-based phishing detection
  • Feature extraction from websites
  • Machine learning classification
  • Simple and user-friendly interface

My Contribution

Developed the machine learning model, handled feature extraction, and built the web interface using Django. Also worked on integrating prediction results into a user-friendly system.
